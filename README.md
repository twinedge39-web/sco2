# sco2（すこすこ）— 新型スカウター (Ver. 1.0.1)

Windows 10 / 11（x64）向けの軽量PC戦闘力測定ツールです。

2010年の「スカウター」の測定処理を解析した試験的な再現コードを基に、軽量な Win32 GUI と外部階級表 `sco2.txt`（UTF-8）による階級判定を行います。

## 1. 配布ファイルと配置

実行ファイルは GitHub Releases の `SCO2-v1.0.1.zip` から入手できます。ZIP 内の以下の2ファイルを同一フォルダに配置して使用してください（カレントディレクトリや固定パスには依存しません）。

リポジトリのファイル一覧には実行ファイルを含めず、Releases の ZIP で配布しています。

- **`sco2.exe`** — 実行ファイル（Windows x64 / MSVC `/MT` 静的リンクのため、別途 VC++ 再頒布可能パッケージの導入は不要です）
- **`sco2.txt`** — 階級データファイル（UTF-8、タブ区切り）

※ 旧版の `sco.exe` / `sco.txt` は一切参照・上書きしません。

## 2. 使い方

### GUI モード（通常起動）
1. `sco2.exe` を起動すると、メインウィンドウ（タイトル：`sco2`）が表示されます。
2. **「計測する」** ボタンを押すと「測定中…」となり、ワーカースレッドで1回の測定が実行されます（測定中もウィンドウの移動や終了が可能です）。
3. 計測が終わると測定結果（戦闘力の数値および `sco2.txt` に基づく階級名）が表示されます。続けて **「計測する」** を押すことで何度でも再計測できます。

### CLI モード・セルフテストモード
PowerShell やコマンドプロンプトから以下のオプションで実行できます（既存コンソールに自動接続して結果を表示します）。

```powershell
# コンソール上で1回計測して結果を表示
.\sco2.exe --cli

# 自動検証を実行し、結果表示＋ sco2-test.log (UTF-8) に保存
.\sco2.exe --self-test
```

## 3. `sco2.txt` の形式と判定仕様

- **文字コード**: UTF-8（BOMあり・BOMなし両対応）
- **行形式**: `戦闘力の下限（正の整数）<TAB（1つ以上）>表示名`
- **空行・コメント**: 空行および先頭が `#` の行は無視します。
- **検証方針**:
  - 下限値は**厳密な昇順**である必要があります。
  - タブ欠落、数値不正、下限値の重複・順序逆転、文字コード不正などが1行でも存在する場合は破損データとして扱い、該当行番号と理由を画面に表示します（不完全なデータの暗黙採用や旧 `sco.txt` へのフォールバックは行いません）。
  - `sco2.txt` が欠落またはエラーの場合でも、戦闘力の数値自体は計測・表示できます。
- **階級判定ルール**:
  - 測定値を超えない最大の下限値を持つ行を採用します（例：`530,000 = フリーザ第1形態`）。
  - 最小下限値（`5`）未満は `《 判定対象外 》` と表示します。
  - 最大下限値（`150,000,000`）を超える場合は最高位を保持し、`（測定限界超過）` を付記します。
  - 表示名の末尾にすでに `級` が付いている場合は、`級` を二重付与しません。

## 4. ビルド方法

Visual Studio 2022 Build Tools（MSVC x64）がインストールされた環境で、同梱のバッチファイルを実行してください。

```bat
build_sco2_windows.bat
```

## 5. 注意事項

- 本ソフトの測定式は試験的な再現コードであり、旧版バイナリとの完全な数値一致を保証するものではありません。
- 戦闘力の表示は小数部分を切り捨てます。計算と階級判定には切り捨て前の値を使います。
- 測定値は実行環境や負荷の影響を受けるため、CPU性能の厳密な比較には使えません。
- `sco2.txt` に含まれる階級名・数値にはゲーム用の創作設定が含まれており、原作の公式確定値を示すものではありません。
