# SCO2（すこすこ）— 新型スカウター

Windows 10 / 11（x64）向けの軽量PC戦闘力測定ツールです。
2010年の「スカウター」に着想を得て、C++17 / Win32 GUIで制作した独立した試作アプリです。

## 実行方法

同じフォルダに `sco2.exe` と `sco2.txt` を置き、`sco2.exe` を起動してください。
「計測する」ボタンでCPU処理に基づく戦闘力と階級を表示します。測定はワーカースレッドで実行され、再計測できます。

## 収録ファイル

- `sco2.cpp` — C++17 ソースコード
- `sco2.txt` — UTF-8（BOMあり・なし両対応）の階級データ
- `build_sco2_windows.bat` — MSVC x64 ビルドスクリプト
- `sco2.exe` — Windows x64 実行ファイル（配布時に同梱）

旧版の `sco.exe` / `sco.txt` とは別ファイルで、上書き・参照はしません。

## 階級ファイルの仕様

1行ごとに `戦闘力の下限<TAB>表示名` を記載します。下限値は正の整数かつ厳密な昇順です。
空行と先頭が `#` のコメントは無視します。
判定は測定値以下の最大の下限値を採用し、53万は「フリーザ第1形態」です。
ファイルがない・不正な場合も数値測定は可能ですが、階級の読み込みエラーを表示します。
階級名には創作表現が含まれ、公式設定値のみを掲載したものではありません。

## ビルド

Visual Studio 2022 Build Tools の C++ 開発環境で：

```bat
build_sco2_windows.bat
```

テストおよびCLI測定：

```bat
sco2.exe --self-test
sco2.exe --cli
```

## 開発状況

実験的な測定エンジンを搭載した初期版です。測定値は環境や負荷の影響を受けます。
旧版EXEとの一致、CPU性能の厳密な比較を保証するものではありません。
